# 首板承接转强：从盘中提醒改为「涨停晋级观察」卡片

**日期：** 2026-11-23
**范围：** 首板承接链（`FirstBoardReclaimTracker` / `FirstBoardReclaimPolicy`）与选股页候选池展示。

## 变更

首板承接转强以前是盘中通知（`firstBoardReclaim`）。现在不再推送，改为写入本地记录，并在选股页
「👀 持续观察池」下方单开一张「🔥 涨停晋级观察」卡片，盘后和进程重启后都能看到。

- 判定口径不变：首板后第 1–3 个交易日、日内低点较开盘低至少 0.5%、低点稳定 5 分钟后收复开盘价、
  MA5 乖离 ≤10%，且资金流未显示“主力借反弹出货”。
- 同一交易日同一代码只保留最新一次命中，避免资金过滤回滚后重复触发把卡片堆满。
- 记录保留最近 14 个自然日（约 10 个交易日），最多 200 条。
- 记录不依赖提醒开关：它是选股数据，不是盘中打扰；只要监控服务在交易时段运行就会积累。
- 资金在出货时不记录，并回滚 tracker 的 `emitted`，资金转好后同一形态仍可再记入。

## 卡片内容

按交易日倒序分组，每只股票可展开查看：

| 字段 | 说明 |
|---|---|
| 触发 | 触发时刻与“首板后第 N 交易日” |
| 首板日 | 产生当前 1 连板的首板日 |
| 盘口快照 | 开盘价、日内低点、触发价、低点较开盘幅度 |
| MA5 乖离 | 触发时价格相对动态 MA5 的乖离 |
| 资金承接 | 当日 / 近 5 分钟 / 近 15 分钟主力净流入占比与结论 |
| 板块 | 候选所属板块标签 |
| 观察池现状 | 当前观察池档位；已淘汰时明确标注仅保留当日记录 |
| 止损参考 | 观察池候选仍保存的失效价 |
| 操作提示 | 观察线索不等同买入确认，不追涨停 |

## 代码位置

- `core/FirstBoardReclaimObservation.kt`：记录模型、JSON 编解码、去重与保留期清理。
- `core/Store.kt`：`firstBoardReclaimObservations` 落盘与原子追加。
- `monitor/MonitorService.kt`：`checkFirstBoardReclaimObservations` 只记录不推送。
- `monitor/Repo.kt`：供选股页读取的运行时快照。
- `ui/ScreenFragment.kt`：「🔥 涨停晋级观察」卡片。
- `test/.../core/FirstBoardReclaimObservationTest.kt`：编解码、去重、过期清理与损坏容错测试。

## 边界

- 卡片不创建买入计划、不改变观察池状态机、不声称买点确认。
- 盘中采样仍依赖当日实时行情；监控服务未运行或行情缺失时不产生记录。
- “首板后第 N 交易日”按指数日线给出的真实交易日计算，法定节假日不计入。
