# 反弹布防兜底、封板探测与风险动作分层

日期：2026-10-22

当天三只持仓各暴露一个能力缺口：中天科技浅坑深 V 无提醒、招商证券低位轻仓被喊「退出优先」、华天科技突发封板全靠盯盘。以下为对应的口径修订与新增能力。

## 已落地

- 反弹跟踪新增第二条布防路径「日内坑 ≤ -3%」：高波动票的 1.2×ATR 阈值被 -5% 钳位挡住时，3 个点级别的 V 型收复不再整段漏掉；「深跌回升」恐慌坑口径不动。
- 破位动作分层（HoldingExitStage.NOTICE 破位风险提示）：基本面未亮红灯 + 价格处区间低位 + 仓位轻（<5% 总资金）三条同时成立时，命令式减仓/清仓降级为「风险提示、去留自定」；红灯 / 高位 / 重仓维持现行强度，深套仍走 DEEP_T 框架。
- 基本面管道支持金融企业：现金流量表/资产负债表缺失时保留利润表口径（现金项记空不记 0），存贷双高 / 销售收现比 / 净现金等工业口径检查对银行/保险/证券/多元金融跳过；数据口径不全时低评分不判亮红灯（业绩变脸、公告风险、扣非异常等实锤仍红）。
- 新增三个盘中/日级探测器：
  - 封板冲刺预警（SealSprintTracker）：2 分钟涨 ≥3% + 量能 ≥5× 基线 + 创日内新高，识别点火形态（实测华天 13:55 点火、13:58 封板，可提前约 2 分钟提示）；
  - 封板 / 炸板提醒（LimitSealTracker）：触涨停报封板（含封单金额），回落报炸板；此前持仓封板从不推送；
  - 事件后蓄势观察（EventCoil）：利好落地公告（重组过户/注册批复/业绩预增/中标/增持/回购）+ 放量后缩量回踩不破，给观察注记（实测华天 10-21 即成立，早于封板一天）。
- 持仓 Tab「今日要点」置顶高亮事件后蓄势（警示色 + 大一号）；公告清单按需轻量补拉（12 小时节流），不依赖基本面按需补拉触发。

## 口径边界

- 封板冲刺的可抓提前量就 2~3 分钟：无板块先动的个股点火在那之前没有盘口痕迹，不承诺更早。
- 事件后蓄势是概率线索不是承诺：只提示「放量突破时值得盯」，不给买入指令、不改趋势判断。
- 缓释只降动作不降信息：破位事实与自动风险参考线始终在文案里；总资金未填写时缓释不生效（按旧口径）。
- 金融企业的评分只含可得维度（扣非、成长），低分不作恶化判定；「没数据」不写成「报表差」。
- 风险提示类（封板/炸板/冲刺）按跌预警同口径：不占共享推送预算、只看 alertsEnabled；冲刺/封板/炸板各有每日次数上限。
