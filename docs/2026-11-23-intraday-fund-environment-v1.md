# 盘中资金环境 v1（只读提示）

日期：2026-11-23

## 目标

把「当日大盘资金」和「个股资金流入流出」组合成一条盘中提示，帮助判断持仓该偏持有、观察还是减仓提示。v1 只做**只读提示**，不生成买卖计划、不改做 T 份额。

## 明确不做

- 不修改 `IntradayTactics` 的信号触发、数量建议和做 T 份额。
- 不写入 `DailyAdvicePlan`，不产生命令式买卖。
- 不因为单日资金数据把轻仓、深套或基本面未亮红灯的持仓升级成“卖出”。
- 不把行业板块合计说成精确的全市场资金流。

## 数据口径

- 大盘：东方财富行业板块（`m:90+t:2`）的 `f62` 主力净流入与 `f6` 板块成交额，按成交额加权。
  - `净占比 = Σf62 / Σf6 × 100%`
  - 同时看流入板块占比（`f62 > 0` 的板块数 / 有效板块数）。
- 个股：沿用 `FundFlowPolicy` 的当日主力净占比（`mainNetPct`，门槛 ±3%）。
- 两者都是按订单规模估算，不代表机构身份，不构成交易指令。

## 方向与确认

| 档位 | 条件 |
|---|---|
| 流入 | 加权净占比 ≥ +2.0%，且流入板块占比 ≥ 55% |
| 流出 | 加权净占比 ≤ -2.0%，且流入板块占比 ≤ 45% |
| 中性 | 其余 |
| 数据不足 | 有效板块 < 10，或板块合计成交额 < 200 亿 |

- 方向切换需要**连续 2 次同向快照**（板块资金 5 分钟一轮，约 5–10 分钟确认）。
- 接口失败时沿用上一次确认档位并标记 stale，不把“数据缺失”误报成“资金转中性”。

## 展示与提醒

- 持仓详情新增「资金环境」一行：大盘方向 + 个股方向 + 一句操作语气（持有 / 观察 / 反弹先减），不出现具体股数。
- 档位跃迁时推送一条低频通知：
  - 只在交易时段、有持仓、`alertsEnabled && intradaySignalEnabled` 时发送；
  - 每人每天最多 3 条，间隔至少 30 分钟；
  - 正文最多列 6 只持仓，附“按订单规模估算、不构成交易指令”声明。
- 通知使用独立 `kind/triggerType = market_fund_flow`，与买卖信号在提醒历史里区分。

## 两周噪声评估（决定是否接执行层）

先只观察，不调阈值。记录：

1. 每个交易日方向跃迁次数（目标：≤ 3 次/日，超过说明阈值或确认次数偏松）。
2. 跃迁后 30 / 60 分钟沪指与持仓个股的方向命中率。
3. “转向后很快反向”的误报日数（例如 30 分钟内反向超过 0.5%）。
4. 实际通知条数与你主观“值得看一眼”的比例。

两周后再决定：

- 是否把资金环境作为 `IntradayTactics` 的前置闸门或做 T 份额降档因子；
- `ENTER_NET_RATIO_PCT`、板块扩散比例和确认次数是否需要调整；
- 是否需要接入指数级资金流接口做交叉验证。
