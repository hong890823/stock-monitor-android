# 启动初期发现：华东重机、华胜天成原型回放

日期：2026-11-19（Asia/Shanghai）。本文只验证原型规则的触发时点，未修改生产交易规则，未接入通知链路。

## 原型规则

只使用截至当前 5 分钟端点已产生的数据：

1. 收盘价突破前 20 个交易日的最高收盘价（平台突破）。
2. 当日涨幅 >= 3%（相对前收盘）。
3. 该 5 分钟成交量 >= 当日前 6 根均量的 2 倍。
4. 动态 MA5 乖离 <= 8%（当日实时价替换当日收盘价）。
5. 现价未处于涨停价。
6. 同一股票同一交易日最多一次。

回放代码：`app/src/test/java/com/example/stockmonitor/analysis/LaunchDiscoveryReplayTest.kt`，直接读取 `entry-timing-2026-11-19` 样本，不改动生产类。

## 关键限制

- 华东重机 11-12 09:50 的 5 分钟 K 线直接打到涨停价 5.29 并封住到 13:50，触线与封板在同一根 K 线内，无法证明存在“涨停前”的成交机会。可操作的信号是 13:55 炸板后 5.13，而不是早盘。
- 华胜天成 11-06 盘中最高 13.24 曾越过平台，但收盘 12.68 低于 12.70 的平台收盘新高，日线条件不成立，因此不触发。若改用“盘中最高价突破”，11-06 会提前触发但在 11-09 回落，属于失败信号。
- 分钟样本只有 11-12～11-19，11-12 之前只有日线，因此能证明“日线条件最早在 11-12”，不能证明盘中更早时刻的行为。
- 只有两只票，无法估计误报率；规则参数（3%、2 倍量、8%）尚未做参数敏感性验证。
- 触发时刻是 5 分钟端点，不是精确通知时间。

## 海立股份 600619：首板后承接买点

样本：腾讯前复权日线 + 新浪 5 分钟线，2026-11-03～11-19，保存于 `app/src/test/resources/entry-timing-2026-11-19/600619.json`。回放测试：`HailiReclaimReplayTest` 与 `LaunchDiscoveryReplayTest`。

行情：11-17 首板 13.10（+9.99%）；11-18 高开 13.50、低 13.20、收 13.70（+4.58%）；11-19 开 13.56（水下）、最低 13.15、封 15.07（+10.00%）。

| 日期 | 盘面 | 启动发现原型 | 首板回踩观察（现有线上逻辑） |
| --- | --- | --- | --- |
| 11-13 | 冲高 12.50 后回落，收平 11.90 | 09:55 @12.33 触发，属假启动；11-16 低点 11.66 会先触发止损 | 不适用 |
| 11-17 | 首板，13.10 收盘封板 | 09:55 @12.75 触发，较封板早约 25 分钟（当日 +7.05%，乖离 5.32%） | 不适用（前一日连板数为 0） |
| 11-18 | 高开 13.50 后回踩 13.20，收 13.70 | 无触发：高开时乖离约 9.6% 超 8%，回踩时当日涨幅不足 3% | 09:55 @13.72 |
| 11-19 | 开 13.56 水下，分歧下探 13.15，09:50 收复开盘价，午后封板 | 无触发：需同时站上 13.70 且涨幅 ≥3%（约 14.11），该价位乖离已超 8% | 09:50 @13.57 |

结论：

- 启动发现原型能提前到首板日早盘，但抓不到 11-18、11-19 的承接买点；它的 8% 乖离与 3% 涨幅门槛恰好与首板后 2–3 日的分歧形态冲突。
- `FirstBoardReclaimTracker` 能抓到 11-18 09:55 与 11-19 09:50 两个买点，说明形态逻辑本身没问题。
- 因此本次漏报的根因在候选入池：`MonitorService.addLimitContinuationCandidates` 对涨停池股票是无条件入池的，若 11-17 收盘涨停的海立不在 `observationPool`，应检查当日涨停池扫描是否成功、候选是否被淘汰、提醒开关与行情日期。
- 11-13 的假启动说明原型不能作为唯一买点确认，需叠加“信号后不破位”的确认或收盘确认。

## 观察池追踪日志（2026-11-19 新增）

为定位“涨停股为什么没有进入观察池、为什么没有发提醒”，`MonitorService` 增加了统一 tag 的结构化日志，实现在 `app/src/main/java/com/example/stockmonitor/monitor/ObsPoolTrace.kt`。

| 事件 | 触发点 | 关键字段 |
| --- | --- | --- |
| `limitScan` | 每轮涨跌停池刷新后 | 数据源、涨停数、进入持续观察/龙头分流的数量、全部代码与连板数 |
| `poolAdd` | 涨停池写入观察池后 | 新增代码、名称、策略、连板数、来源 |
| `poolStreak` | 连板数变化 | 旧值→新值 |
| `poolStage` | 复评后阶段变化 | 旧阶段→新阶段、复评天数、连板数、reason |
| `poolAge` | 复评天数增加 | 旧值→新值 |
| `reclaimGate` | 首板提醒门控 | eligible 及原因：strategy / streak / age / eliminated / staleQuote |
| `reclaimAlert` | 观察提醒实际发出 | 代码与触发价 |
| `reclaimBudgetBlocked` | 推送预算不足 | 代码 |

`reclaimGate` 每个交易日、每只股票、每种结论只记一条，其余事件按状态变化记录，不会随 15 秒轮询刷屏。排查示例：

```bash
adb logcat -c && adb logcat -s ObsPoolTrace | grep -E 'limitScan|600619'
```

遇到同类漏报时，先看当日 `limitScan` 里是否包含该代码，再看 `poolAdd`/`poolStage` 是否把它淘汰，最后看 `reclaimGate` 给出的排除原因。

## 2026-11-19 收敛优化

回放暴露的两个缺口已在现有逻辑上修掉，未新增扫描链路：

1. **观察窗口改按首板日起算**。`FirstBoardReclaimPolicy.windowEligible` 以涨停池入池日（即首板日）为起点，按工作日计算第 1–3 个交易日；`addedDate` 缺失时才回退 `observedDays`。华胜天成 11-18 在旧口径下 `observedDays=4` 被排除，新口径是首板后第 3 个交易日。
2. **观察事件增加 10% 的 MA5 乖离边界**。动态 MA5 用观察池缓存的日线 + 实时价计算，不额外请求接口；乖离 >10% 不发观察并记录 `reclaimGate detail=bias=…`。华胜天成 11-16 的 11.0% 乖离会被拦下，海立股份 11-19 的 5.7% 正常通过，提醒正文会带上乖离。
3. **门控日志按原因类别去重**，价格波动不会把 `reclaimGate` 刷屏。

新增测试：`FirstBoardReclaimPolicyTest`（窗口/周末/回退/价格边界）、`HailiReclaimReplayTest` 补充乖离文案断言。定向测试全部通过。

仍未解决：首板前的启动发现需要独立的日线平台数据源，当前只在测试里保留了原型，没有接入生产。
