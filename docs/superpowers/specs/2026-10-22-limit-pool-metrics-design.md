# 涨跌停池指标设计

## 目标

在“市场 → 涨跌停”中提供可核验的封单、封单成交比、封单流通市值比、开板次数和封板时间，并将涨停与跌停完整列表拆成两个入口。

## 数据口径

- 主源为东方财富涨停池与跌停池，查询日期为当前交易日。
- 涨停池使用 `fund`、`amount`、`ltsz`、`zbc`、`fbt`、`lbt`、`lbc`。
- 跌停池使用 `fund`、`amount`、`ltsz`、`oc`、`lbt`；接口没有稳定提供首次封板时间时保持为空。
- `fund`、`amount`、`ltsz` 均按元存储。封单成交比为 `fund / amount * 100`，封单流通市值比为 `fund / ltsz * 100`。
- 东方财富请求失败时退回现有新浪近似扫描；近似数据缺少的指标显示“—”，不得推算。

## 展示口径

- 一级卡片每侧最多展示 8 只，按东方财富池原顺序展示。
- 顶部显示涨停与跌停数量。
- 每只股票展示封单金额、封单成交比、开板/炸板次数和首封/末封时间；缺失字段显示“—”。
- 页面提供“查看全部涨停（N只）”和“查看全部跌停（N只）”两个独立入口。
- 报告注明来源；使用新浪兜底时明确标注“近似阈值口径”。

## 风险边界

- 封单金额是时点快照，不代表后续封板稳定性。
- 封单成交比受当日成交额影响，必须与绝对封单金额一起看。
- 开板次数和封板时间以数据源统计为准，不用应用内抽样结果补写历史。
