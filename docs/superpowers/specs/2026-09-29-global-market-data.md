# 港美股数据链路改造规格

## 目标

提升工具页港美股基本面分析的数据可靠性和可解释性：美股优先使用 SEC 官方财务数据，行情使用可配置的商业行情源并保留现有公开源兜底；港股保留独立的行情/公告链路，不再把 Nasdaq 数据误当成完整财务数据。

## 范围

- 美股：股票搜索、SEC 公司识别、XBRL 财务数据、当前行情与估值计算。
- 港股：股票识别和行情继续支持；公告/财务数据源状态明确展示，缺失时不生成过度确定的结论。
- 报告：显示数据源、最新财务期间和数据完整度；有数据时补充利润、现金流、负债和估值判断。
- 失败处理：单个数据源失败只影响对应模块，不让整个分析无提示地失败。

## 非目标

- 不在 APK 中硬编码第三方 API 密钥。
- 不承诺免费接口提供港股全部实时或机构数据。
- 本次不重写 A 股基本面分析逻辑。

## 数据源策略

1. 美股财务：SEC `company_tickers.json`、`submissions`、`companyfacts`。
2. 美股/港股行情：优先读取可选的 Twelve Data API Key；未配置或请求失败时回退到现有公开行情源。
3. 港股公告：暂不伪造结构化财报字段；报告明确标记公告/财务字段未接入或缺失。

## 约束

- Android 端继续使用现有 `HttpURLConnection`，不增加网络库。
- SEC 请求必须带明确的 User-Agent，并进行低频缓存/重试，避免重复拉取公司元数据。
- 所有解析逻辑先写单元测试，测试使用固定 JSON，不依赖实时网络。
- 缺失数据必须显示为缺失，不用 A 股字段补齐，也不生成“没有风险”一类过度结论。

## 验收标准

- 输入 `NVDA` 能通过本地映射或 SEC ticker 映射得到 CIK。
- 固定 SEC Company Facts JSON 能解析营收、净利润、现金流、现金、债务、毛利率、营业利润率和自由现金流。
- 当行情可用时能计算市场值、PE/PB，并在报告中注明“SEC + 行情源”。
- SEC 或行情源失败时，报告仍能生成基础结果，并明确显示缺失项和失败源。
- 港股分析不会把 Nasdaq 的美股字段误展示为港股完整财务数据。
