# 成交额环境质量与冲高做T过滤归档

**归档日期：** 2026-10-13  
**项目：** `stock-monitor-android`  
**变更：** 将两市成交额从单一阈值升级为成交额、连续性、指数位置和板块宽度联合判断，并用于盘中做T提醒、市场总结、持仓报告与复盘。

## 策略口径

- 全天预估成交额 `>= 20000` 亿元仅代表高成交活跃度，不能单独确认后续动能。
- 此前完整收盘日最近 3 个交易日每天 `>= 17000` 亿元且三日均值 `>= 18000` 亿元，作为量能持续性证据；今日预估不计入连续性。
- 行业与概念板块上涨占比均 `>= 60%`，沪指涨幅不低于 0 且距日内高点小于 1%，共同支持“强势延续”。
- 满足高成交额、指数和宽度但连续性不足时为“高成交额待确认”；实际观测到指数滞涨或板块扩散不足时为“放量分歧”。关键证据缺失时为“数据不足”，沿用原个股逻辑，不将缺失推断为分歧。
- 只有强势延续才暂缓普通冲高做T；风险信号优先，缺失证据不猜测。

## 接入与文案

- 盘中提醒、市场总结、持仓报告与复盘使用同一环境质量模型和动态证据。
- 报告只引用程序实际持有的证据；当前行业/概念板块宽度不能写成全市场股票上涨家数。
- 北向、两融、IPO、股东减持等未接入本模型，不会被默认描述为利好或利空。
- 持仓事件新增环境字段为可选字段，旧版事件 JSON 缺少这些字段时仍采用默认状态和空原因列表。

## 验证与限制

- `IntradayTacticsTest`、`MarketSummaryBriefTest`、`StrongContinuationEventTest` 覆盖环境阈值、风险优先级、动态盘面结论和旧 JSON 解码。
- 单日高成交额不能保证行情继续上涨；今日预估也不能替代收盘确认。本功能只降低把“天量”机械等同于“好行情”的误判，不是买卖指令。

## 最终复核

- 连续性只读取此前完整收盘采样，缺失收盘日保留断点，不把盘中预估混入历史序列。
- 2026-10-13 Android 全量单元测试 `429` 项通过，Debug 构建通过。
- 持续性从单一 `1.5 万亿` 底线升级为“`1.7 万亿`最低值 + `1.8 万亿`三日均值”，避免普通活跃水平被误判为增量行情持续。
