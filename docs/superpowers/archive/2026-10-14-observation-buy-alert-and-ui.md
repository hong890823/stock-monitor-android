# 观察池买点提醒与选股页标识归档

**归档日期：** 2026-10-14  
**项目：** `stock-monitor-android`  
**目标：** 当观察池候选经过持续复评，首次进入“可介入候选”时通知用户，并在选股页清晰置顶展示。

## 功能口径

- 只有候选从其他阶段首次进入 `BUY_CANDIDATE` 才发送提醒。
- 候选持续停留在“可介入候选”不会重复提醒；回落后再次确认可以再次提醒。
- 提醒沿用现有“行情提醒”和“买卖点 / 做T提醒”开关、通知权限、震动和高优先级通知通道。
- 提醒正文包含代码、策略类型、现价、确认理由和止损参考。
- `NEAR_ENTRY` 候选盘中每 60 秒复评一次，用于捕捉回踩企稳和承接恢复；其他候选仍按交易日复评。
- 趋势入场每次复评使用最新价格、成交量、当日高低点和市场基准重新计算，旧的选股结果只作为异常时的兜底。

## 界面变化

- 选股页观察池增加绿色“可介入候选 · 买点已确认”独立提示区。
- `BUY_CANDIDATE` 股票自动置顶。
- 股票名称显示 `🟢【可介入】`，详情首行显示“买点已确认”。
- 其他观察对象与可介入候选之间增加分隔线。
- “把当前选股结果加入观察池”改为“手动补充当前结果到观察池”，并说明正常扫描结果会自动进入观察池。

## 代码与测试

- 新增 `analysis/ObservationBuyAlert.kt`，集中处理状态转移判断和提醒文案。
- `MonitorService` 接入买点状态转移提醒、盘中复评节流和最新趋势重算。
- `ScreenFragment` 接入候选置顶、标签和手动补充说明。
- 新增 `ObservationBuyAlertTest`，覆盖首次进入、重复候选和重新确认提醒。
