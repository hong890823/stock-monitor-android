## 口径要点

- **强度分档**（模块 D）：多头排列 + 贴 MA5（2% 容差）+ 近 5 日站稳 → 强势，浅锚 `[anchor×0.99, anchor×1.02]`，文案写明「等不到 M20 不硬等」；其余维持 M20 口径；破 M20 / 趋势转弱不给区间。锚位候选取 `max(MA5, 突破位)`，突破位只在现价还贴着它时有效。
- **可达性护栏**：建议价距现价超过 2.5×ATR 时注记「深回踩口径大概率到不了」并推浅锚；无 ATR 数据不猜。
- **分歧日判定**（模块 A）：高开 ≥+0.4% + 最高 ≥+1.5% 且收盘 ≤ 高开幅度 60% + 量能环比 ≥+5% + 收盘在前 5 日均线上方，四条缺一不判；资金腿按收盘分承接三档，政策腿恒为未知。
- **证伪状态机**（模块 B）：D+1 观测、D+2 中阳→洗盘确认 / 弱势→提前降级 / 中性→留最后观测日；窗口内无中阳按宁降勿拖降级；解析结果持续到 D+5 回常规；新分歧日重开周期。中阳 α/β 双口径实现，默认 α。
- **状态矩阵**（模块 C）：REBOUND_HOLD 留底仓/分批进、WATCH 不动或只准备、DOWNGRADE 冻结新增（重仓红灯与轻仓只提示分措辞）；全局禁「等连续大阳线追确认」（拦截仍走既有 MA5 乖离上限）。
- **分批**（模块 E）：40/30/30（浅锚缩量企稳 → 证伪确认 → 突破/二踩）；收盘跌破失效参考取消全部后续批次；只是切分同一条额度，不放大额度。
- **整体建议瘦身**：只点名要动手/要核实的票——多只确认处置补一行「今天要处理」，风险观察与深套最多点前两只 + 总数，持有观察报数不点名（保留「不用动」信号）；逐票明细留在逐股报告。

## 明确不动的口径

- 恐慌坑（`DipReboundEngine` / `ReboundTracker` 深跌回升）口径不变，分歧日是高开回落，两个状态机不串口。
- 深套 `T_ONLY`、ST 涨跌停、止损下沿、盈亏比 ≥2、仓位/风险预算约束全部沿用。
- `IntradayAdditionPolicy` 的数量与风险门槛不动；分批只做**作废线口径对齐**（收盘破失效参考 ↔ `INVALIDATED`）。
- 盘中资金环境 v1 在 2026-12-07 噪声评估前不作为分批触发条件。
- 不预测个股涨跌；「洗盘/证伪」只对大盘指数定性。
